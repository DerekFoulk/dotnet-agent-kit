// A type's static constructor is private: C# allows no access modifier on one (CS0515), and every one measured is
// (2026-11-11: all of them in the public types of a fresh pwsh 7.6 session, 479 to 498 depending on what it has
// loaded, and 1636 of 1636 with every assembly in pwsh's folder loaded). So TypeInitializer returns a non-public
// member, and its uses past running it (does one exist, what's in it, run it again with Invoke) all read a type's
// internals. Running it is RuntimeHelpers.RunClassConstructor's job, which runs it only if it hasn't run; that method
// is marked RequiresUnreferencedCode, so in a trimmed app touch one of the type's static members instead.
