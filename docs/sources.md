# Practitioner sources

Books, blogs and talks that inform a standard or profile (brief §4). They aren't a rule layer of their own. Each is read once, when the standard it informs is written or revised, and a rule taken from one applies only after the owner ratifies it. Agents don't read these while working.

| Source | Informs | When |
|---|---|---|
| Kent Beck, [Canon TDD](https://newsletter.kentbeck.com/p/canon-tdd); Martin Fowler, [Test Driven Development](https://martinfowler.com/bliki/TestDrivenDevelopment.html) | Testing standard (`docs/standards/testing.md`, ADR-0018) | v0.1 (read 2026-11-01) |
| Mads Kristensen ([Visual Studio Blog](https://devblogs.microsoft.com/visualstudio/author/madsk/)) | Visual Studio setup and tooling notes | After v0.1 |
| James Montemagno ([montemagno.com](https://montemagno.com/)); David Ortinau ([.NET Blog](https://devblogs.microsoft.com/dotnet/author/davidortinau/)) | `maui` profile | When that profile is built |
