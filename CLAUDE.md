## Claude Code notes

- **Rules:** `.claude/rules/` holds generated, path-scoped rule summaries. Each rule's full text, reason and sources are in `docs/standards/`.
- **Code review:** before opening a PR, run the `reviewer` subagent (`.claude/agents/reviewer.md`) on the branch (DOD-003, ADR-0067). It hasn't seen your work, so it reviews with fresh eyes, against `docs/code-review.md`. When a review lands on the PR, answer it with the `address-review` skill. Wait for CI with `Wait-PullRequest` (`KitReview.psm1`) in the foreground, as `finish-work` step 4 says ("Wait cheaply"); the desktop app's PR monitor stays off unless the owner asks for it.
- **Claude usage** (ADR-0068): each model call carries the whole conversation. Start each new PR's work in a fresh session; follow-ups to an open PR stay in its session. `finish-work` steps 2 and 4 say how review and waiting keep calls few. This is Claude Code's billing; other tools may bill differently.
- **Permissions:** `.claude/settings.json` keeps precise rules (ADR-0026) and allows routine workflow commands, such as `gh` reads and the kit's scripts, so they don't prompt (ADR-0075 lists them). It denies reading secret files. In both modes it asks before installing tools, running `New-KitApp` (in the kit only: an app's copy leaves out rules for kit scripts the app doesn't get), switching with `Set-AgentMode -Mode`, `git reset --hard`, `git clean`, `Invoke-Pester` typed into the PowerShell tool (run Pester tests in a child `pwsh`: in the kit, with the launcher in AGENTS.md's Commands table; ADR-0092), the module installs `Initialize-DevMachine` prints, deleting or force-pushing a branch, changing visibility, rulesets, branch protection or merge settings, deleting a repo, releases, `gh api` calls that write, and editing agent config, connectors or the mode files. Review mode adds asks before merging a PR, editing repo settings, adding packages and editing build or CI files, in your own `.claude/settings.local.json` (ADR-0035). Pushes aren't matched by text: GitHub's "main protection" ruleset guards `main`. If a rule blocks something legitimate, stop and ask the owner; don't rephrase around it.
- **Shell:** on Windows, run the kit's scripts with the PowerShell tool (`pwsh`). Read and search files with the Read, Grep and Glob tools, and run read-only git (`git log`, `git diff`, `git show`) in the Bash tool, and filter `gh` output with its `--jq` rather than a PowerShell pipeline: Claude Code runs those without a prompt and checks their paths and flags itself, while PowerShell's `Get-Content`, `git log` or `| ConvertFrom-Json` prompts (ADR-0075).
- **Microsoft Learn MCP server:** `.mcp.json` configures it. Claude Code asks once per user before it connects a project server. Use it to check current Microsoft guidance before writing .NET code.
